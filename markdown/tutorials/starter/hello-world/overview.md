# Tutorial - My First Pipeline

A backend extension on the Shopgate CONNECT platform enables you to extend existing backend functionalities like the integration of custom cart logics or implementing a loyalty program.

In this tutorial we will learn how to create the first extension and get more insights about how to work with the platform.

> **Prerequisites:**
