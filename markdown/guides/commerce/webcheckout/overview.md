# Web Checkout


## Overview

The Web Checkout is an easy way to integrate the checkout of any
shopping cart system into the Shopgate app. From start to cart,
every page is managed, optimized, and rendered by Shopgate. When a
shopper enters the checkout, he is automatically redirected to
the checkout of the shop system.


This integration is seamless. The shopper does not need to log in
again and the cart transfers automatically. Therefore, the cart
is completely managed by the shop system and gets manipulated by the
app.
