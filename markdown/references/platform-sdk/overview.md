# Platform SDK

This section describes the Platform SDK commands:

Action|Description
---|---
[login](login.md)|Log in to Shopgate CONNECT
[init](init.md)|Initialize a new project 
[extension create](extension.md#create)|Create a new extension
[extension attach](extension.md#attach--detach)|Attach an extension to your Sandbox app
[extension detach](extension.md#attach--detach)|Detach an extension from your Sandbox app
[extension manage](extension.md#manage)|Manage status of existing extensions
[extension upload](extension.md#upload)|Upload an extension to the Shopgate Developer Center
[theme upload](theme.md#upload)|Upload a theme to the Shopgate Developer Center
[backend start](backend.md#start)|Start the backend extension development process
[frontend setup](frontend.md#setup)|Set up the frontend development environment
[frontend start](frontend.md#start)|Start the frontend extension / theme development process
