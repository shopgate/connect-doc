# Filters

## Price Range

| Name | Description | Props |
| - | - | - |
| `filter.price-range.before` | Components are rendered **before** the price range filter. | `filter` - The filter configuration |
| `filter.price-range` | Components **replace** the price range filter. | `filter` - The filter configuration |
| `filter.price-range.after` | Components are rendered **after** the price range filter. | `filter` - The filter configuration |
