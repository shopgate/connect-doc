# CMS Pages

| Name                  | Description                                           | Props                              |
| --------------------- | ----------------------------------------------------- | ---------------------------------- |
| `page.content.before` | Components are shown **before** the CMS page content. | `pageId` - The ID of the CMS page. |
| `page.content`        | Components **replace** the CMS page's content.        | `pageId` - The ID of the CMS page. |
| `page.content.after`  | Components are shown **after** the CMS page content.  | `pageId` - The ID of the CMS page. |
