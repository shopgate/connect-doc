# Browse (ios11 theme only)

## Lists

### Category List

| Name | Description | Props |
| - | - | - |
| `browse.category-list.before` | Components are shown **before** each category list on browse page. | none |
| `browse.category-list` | Components **replace** the complete category list on a browse page | none |
| `browse.category-list.after` | The components are shown **after** each category list on browse page. | none |

### Search field

#### Scanner icon - since 6.4.0
| Name | Description | Props |
| - | - | - |
| `scanner.icon.before` | Components are shown **before** scanner icon | none |
| `scanner.icon` | Components **replace** scanner icon | none |
| `scanner.icon.after` | Components are shown **after** scanner icon | none |
