# Scanner

## Camera Overlay

| Name | Description |
| - | - |
| `scanner.camera.before` | Components are rendered **before** the camera overlay. |
| `scanner.camera` | Components **replace** the camera overlay. |
| `scanner.camera.after` | Components are rendered **after** the camera overlay. |

## Camera Bar

| Name | Description |
| - | - |
| `scanner.bar.before` | Components are rendered **before** the scanner bar. |
| `scanner.bar` | Components **replace** the scanner bar. |
| `scanner.bar.after` | Components are rendered **after** the scanner bar. |

### Flash Icon

| Name | Description |
| - | - |
| `scanner.flash.before` | Components are rendered **before** flash icon within the scanner bar. |
| `scanner.flash` | Components **replace** flash icon within the scanner bar. |
| `scanner.flash.after` | Components are rendered **after** flash icon within the scanner bar. |

## Browse Page Search Field (iOS only)

| `scanner.icon` | Components **replace** the NavMenu entry. |
