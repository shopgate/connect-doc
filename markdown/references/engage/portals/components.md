# Components

This list documents Portals which are available for general components that are used all over the application.

## Product Image

| Name | Description |
| - | - |
| `components.product-image.before` | Components are rendered **before** the product image. |
| `components.product-image` | Components **replace** the product image. |
| `components.product-image.after` | Components are rendered **after** the product image. |
