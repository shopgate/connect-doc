# General

| Name | Description |
| - | - |
| `app.globals` | Allows you to inject something into the global scope of the application. For example, custom meta information via [react-helmet](https://github.com/nfl/react-helmet). |
| `app.routes` | Allows you to define new routes inside the app's router. |
