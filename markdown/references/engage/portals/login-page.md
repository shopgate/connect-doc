# Login Page

| Name | Description |
| - | - |
| `page.login.before` | Your components are shown **before** the login page content. |
| `page.login` | Your components **replace** the login page content. |
| `page.login.after` | Your components are shown **after** the login page content. |

## Login Form

| Name | Description |
| - | - |
| `page.login.form.before` | Your components are shown **before** the login form on the login page. |
| `page.login.form` | Your components **replace** the login form on the login page. |
| `page.login.form.after` | Your components are shown **after** the login form on the login page. |

## Register Link

| Name | Description |
| - | - |
| `page.login.register-link.before` | Your components are shown **before** the register component link on the login page. |
| `page.login.register-link` | Your components **replace** the register link component on the login page. |
| `page.login.register-link.after` | Your components are shown **after** the register link component on the login page. |

Note: If you only need to change the registration URL, consider overriding [shopgate.user.getRegistrationUrl.v1 pipeline](../../../../static/pipelines/shopgate-user-pipelines.oas2.yml/paths/~1shopgate.user.getRegistrationUrl.v1/post)
