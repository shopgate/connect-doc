# Actions

You can use actions to control your application and data flow.  Actions send data from your application to your store. Learn more in the Shopgate [guide to fetching and processing data](/guides/technical/engage/data-fetching-and-processing) and refer to the official [Redux documentation](https://redux.js.org/basics/actions "Redux Documentation - Actions").

Here we provide you with a list of all available actions.

- [Cart](/references/engage/actions/cart)
- [Category](/references/engage/actions/category)
- [Favorites](/references/engage/actions/favorites)
- [Modal](/references/engage/actions/modal)
- [Page](/references/engage/actions/page)
- [Reviews](/references/engage/actions/reviews)
- [Router](/references/engage/actions/router)
- [Search](/references/engage/actions/search)
- [User](/references/engage/actions/user)
