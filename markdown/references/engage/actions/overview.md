# Actions

You can use actions to control your application and data flow.  Actions send data from your application to your store. Learn more in the Shopgate [guide to fetching and processing data](../../../guides/technical/engange/data-fetching-and-processing.md) and refer to the official [Redux documentation](https://redux.js.org/basics/actions "Redux Documentation - Actions").

Here we provide you with a list of all available actions.

- [Cart](cart.md)
- [Category](category.md)
- [Favorites](favorites.md)
- [Modal](modal.md)
- [Page](page.md)
- [Reviews](reviews.md)
- [Router](router.md)
- [Search](search.md)
- [User](user.md)
