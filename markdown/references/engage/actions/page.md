# Page Actions

* [fetchPageConfig](#fetchpageconfig)

## fetchPageConfig

Retrieves the configuration for a page.

### Usage

```js
import { fetchPageConfig } from '@shopgate/engage/page';

dispatch(fetchPageConfig('page_id'));
```

### Parameters

* `pageId` *(string)*: The ID of the requested page.
