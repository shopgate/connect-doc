# Selectors

You can use selectors to optimize the performance of your application.  Selectors are highly efficient functions used to access data. Learn more in the Shopgate [guide to retrieving data](/guides/technical/engage/retrieving-data) or refer to the official [Redux documentation](https://redux.js.org/recipes/computing-derived-data).
