# Theme API

Shopgate Engage comes with two different themes that are styled to match the following device types: GMD for Android devices and iOS 11 for Apple Devices. The Theme API exposes React components that you can use in your own components to create your features. These components change their styling depending on the device type in which they are rendered.

## Components

* [AppBar](app-bar.md)
* [View](view.md)
* Drawer
* ProductCard
* ProductGrid
* ProductSlider
* TextOption
* SelectOption
* PriceDifference
